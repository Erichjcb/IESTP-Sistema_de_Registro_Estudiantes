# IESTP - Sistema de Registro de Estudiantes

Este es un proyecto de aplicación web desarrollado para gestionar el registro de estudiantes de manera sencilla, rápida y organizada[cite: 1]. Fue creado como parte del proyecto final de curso de la Unidad Didáctica de Modelamiento del Software[cite: 1].

## 🚀 Características del Sistema

El sistema permite realizar todas las operaciones básicas de gestión (CRUD) sin necesidad de una base de datos externa[cite: 1]:
*   **Registrar estudiantes:** Permite ingresar datos completos mediante un formulario[cite: 1].
*   **Buscar estudiantes:** Facilita la localización rápida y en tiempo real de un estudiante específico[cite: 1].
*   **Editar estudiante:** Brinda la capacidad de modificar y actualizar la información de un alumno[cite: 1].
*   **Eliminar estudiante:** Permite remover un registro de la lista cuando ya no es requerido[cite: 1].
*   **Persistencia de datos:** Toda la información se guarda automáticamente en el navegador usando LocalStorage[cite: 1].

## 🛠️ Tecnologías Utilizadas

El sistema fue construido a partir de tres archivos principales[cite: 1]:
*   **HTML (`index.html`):** Contiene la estructura principal del sistema, el formulario de registro y la tabla de visualización[cite: 1].
*   **CSS (`style.css`):** Encargado de la interfaz gráfica amigable y el diseño[cite: 1].
*   **JavaScript (`script.js`):** Maneja toda la lógica del sistema (registro, búsqueda, edición, eliminación y almacenamiento)[cite: 1].

## 💻 ¿Cómo ejecutar el proyecto?

Hacer funcionar este proyecto es muy sencillo. No necesitas instalar servidores locales como XAMPP ni configurar bases de datos como MySQL, ya que el sistema utiliza el almacenamiento local del navegador[cite: 1]. 

Sigue estos pasos:
1.  **Descarga o clona** este repositorio en tu computadora usando `git clone`.
2.  Descomprime el archivo (si lo descargaste en formato ZIP).
3.  Ve a la carpeta del proyecto y **abre el archivo `index.html`** haciendo doble clic sobre él.
4.  El sistema se abrirá en tu navegador web predeterminado (es cien por ciento compatible con Google Chrome y Microsoft Edge)[cite: 1].
5.  ¡Listo! Ya puedes empezar a registrar estudiantes. Si cierras el navegador y vuelves a abrir el archivo, verás que tus datos siguen ahí gracias al LocalStorage[cite: 1].
